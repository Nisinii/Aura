Follow the below steps before running the frontend service.

Most Important: Need node version 22.20.0 as it is compatible with other used dependencies.

1. Open the root directy and use the given command to install node modules - npm install
2. Run the server with the given command - npm run dev
3. If turbopack error comes then change the next.config.mjs with the given script below.

Script

/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    turbopack: false  // <- disable Turbopack
  }
}

export default nextConfig;
